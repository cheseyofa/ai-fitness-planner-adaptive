# 项目更新记录

更新日期：2026-10-03  
项目：AI Fitness Planner 自适应健身规划

本记录概括项目完成环境配置后的主要功能更新和新增服务适配，便于后续查看项目演进；不替代各阶段验收文档，也不列逐文件代码变更。

## 环境与运行

- Windows 开发环境采用 Python 3.11.9 和项目根目录下的单一 `.venv`；以原有 FastAPI、Streamlit requirements 为基础安装，并保存本地依赖快照 `requirements-local.lock.txt`。
- 本地采用 Python 运行前后端、Docker Compose 运行 MongoDB、PostgreSQL 和 Mongo Express 的混合方式。已有 Compose 配置可用于全容器启动，但这次没有重新构建并验收完整前后端镜像。
- FastAPI 与 Streamlit 已有本地启动方式；运行、数据库和依赖验证细节见环境及流程记录。
- `.env` 保存机器本地配置并由 Git 忽略。真实 API 密钥、数据库密码、令牌和用户运行数据不纳入本记录或版本控制。

## 功能更新

- 修复并验证原项目的本地数据库连接、个人资料保存与读取、食品样本重复导入、数据库食品搜索和 FAISS 索引处理问题；明确模型失败时的中文错误提示与工作流失败状态。
- 用户界面主要页面、导航、表单、选项、提示和状态改为简体中文；体重默认使用千克，身高默认使用厘米，并保留接口所需内部字段映射。
- 新增自适应训练闭环：采集恢复信息与训练限制、读取训练历史、计算恢复度与近期负荷、筛选动作、生成当日计划、调整训练量、保存计划与真实训练反馈，并在后续规划中利用反馈。
- 新增本地动作目录、安全筛选、受限计划调整、工具调用回退、训练历史与分类记忆；恢复状态过低、伤痛限制或无合适动作时采用保守安排。
- 新增恢复记录、今日训练、训练历史和训练反馈等中文页面及对应 API。原饮食规划和营养搜索入口继续保留。
- 新增离线测试、协议与故障回退检查、页面交互检查、固定案例评估和可选真实服务验收工具。

## 新增及适配的服务

- **MongoDB**：保存原有用户/食品数据，并新增恢复记录、训练计划、训练反馈、训练历史和用户记忆数据。PostgreSQL 保留在 Compose 配置中，当前 Python 业务流程尚未使用它。
- **DeepSeek**：作为聊天模型服务，支持结构化结果和自适应训练规划。密钥只从本地环境变量读取；模型负责从安全候选动作中选择，关键安全限制和训练量调整由程序执行。
- **wger REST / MCP Streamable HTTP**：新增动作搜索适配和 MCP JSON/SSE 通信，可按 MCP、REST、本地数据的顺序回退。远端数据仅在命中已校对的本地动作及安全映射后用于计划。
- **YouTube Data API**：提供可选训练视频搜索适配；默认模拟服务不返回伪造视频，未配置真实密钥时不提供真实视频结果。
- **LangSmith**：关键模型、工作流节点和工具增加可追踪性；未配置密钥时不宣称已完成云端链路追踪。
- **FAISS 与嵌入服务**：原有食品语义搜索仍依赖独立嵌入 API 密钥和匹配的索引。DeepSeek 聊天密钥不能代替嵌入服务配置。

## 验证摘要

- 环境记录显示 Python 依赖联合安装及主要模块导入通过，FastAPI 和 Streamlit 均完成本机启动检查。
- 数据库与原有运行流程记录包含 Docker Compose 校验、MongoDB/PostgreSQL 连接、食品样本导入、资料读写和本地服务检查结果。
- 自适应阶段记录包含 72 项单元/API/协议/故障注入测试、7 项原有运行修复回归检查，以及中文页面和新页面交互检查通过的结果。
- DeepSeek + MongoDB 自适应训练闭环曾使用独立测试用户完成验证并清理测试记录。MCP、YouTube、LangSmith 的外部服务并未全部配置或完成真实连通验收。

## 当前范围与待配置项

- 生成饮食与语义食品搜索需要相应模型/嵌入服务凭据和有效索引；DeepSeek 凭据本身不提供食品嵌入能力。
- wger MCP、YouTube 和 LangSmith 云服务分别需要相应端点或密钥，目前不应视为默认可用。
- 本地动作目录是小型演示数据；健康评分为工程规则，不能代替医疗评估。项目尚无账号认证/授权体系，不适合直接作为公网多用户服务部署。
- 完整前后端 Docker 镜像构建尚未重新验收；已验证的日常开发方式为 Python 前后端加 Docker 数据库。
